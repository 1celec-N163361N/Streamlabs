# سابا — عدّاد سابثون مباشر

منصة عدّاد سابثون: كل سبسكريب أو بتس أو دونيشن يزيد الوقت على البث، عبر ربط سريع بحساب **Streamlabs**.

> الربط: لصق **Socket API Token** من Streamlabs → العدّاد يبدأ يستقبل الأحداث فورًا. بدون تسجيل وبدون OAuth.

## التشغيل محليًا

```bash
node server.js
```

ثم افتح `http://localhost:4173`.

بدون أي تبعيات — ما يحتاج `npm install`.

## الصفحات

| المسار | الوصف |
|---|---|
| `/` | صفحة الهبوط + الاستوديو (العدّاد، آخر الدعم، الإعدادات) |
| `/overlay?room=XXXX` | أوفرلاي OBS بخلفية شفافة — أضفه كمصدر Browser بمقاس 800×200 |
| `/watch?room=XXXX` | صفحة المشاهدين — شاركها مع الجمهور |

## كيف يجيب الستريمر التوكن؟

1. يدخل `https://streamlabs.com/dashboard#/settings/api-settings`
2. ينسخ **Socket API Token** (مو الـ API Token العادي)
3. يلصقه في الصفحة الرئيسية ويضغط «ربط وتشغيل العدّاد»

## المعمارية

```
assets/js/socket.js   عميل Engine.IO v3 (Socket.IO 2.x) فوق WebSocket خام
assets/js/engine.js   محرّك الوقت + تطبيع أحداث Streamlabs
assets/js/app.js      الاستوديو: الحالة، التغذية، الإعدادات
assets/js/live.js     الأوفرلاي وصفحة المشاهدين (SSE)
server.js             سيرفر Node بدون تبعيات: ملفات ثابتة + حالة الغرف + بثّ SSE
```

- الوقت يُخزَّن كـ `endsAt` مطلق (وليس عدّاد ثواني) فلا يضيع عند تحديث الصفحة.
- كل حدث يحمل معرّفًا فريدًا يمنع العدّ المزدوج عند إعادة الإرسال.
- التوكن يبقى في متصفح الستريمر (localStorage) ولا يُرسل لأي طرف ثالث؛ الاتصال بـ Streamlabs يصير من المتصفح مباشرة.
- حالة كل غرفة في ذاكرة السيرفر، تُبثّ للأوفرلاي عبر SSE.
